# 스페인 내전 연대기

전선이 움직이는 지도와 시간 띠로 따라가는 스페인 내전(1936–1939).
사건 67개, 전선 시기 14개, 세력 13개, 인물 41명, 예술가 17명.

> 1936년 7월 장군들의 쿠데타가 절반만 성공하면서 스페인은 둘로 갈라졌다.
> 그러나 각 진영 안에서도 또 다른 전쟁이 벌어졌다.

## 보기

`index.html`을 브라우저로 열면 됩니다. 별도 빌드나 서버가 필요 없습니다.

1. **지도 연대기**: 시간 띠의 점을 누르거나 `←` `→` 키, 자동 재생으로 사건을 넘깁니다.
   지도는 그 시점의 전선으로 바뀌고, 빗금은 직전 시기에 국민파가 새로 점령한 땅입니다.
   사건마다 대립한 세력, 무엇을 두고 왜 거기서 싸웠는지, 결과와 의미, 인물, 예술가의 시선이 붙습니다.
   지도 밖(파리·모스크바·뮌헨…)의 사건은 화면 가장자리에 방향으로 표시됩니다.
2. **세력과 사상**: 13개 세력을 경제·사회 축과 권력 축에 놓고, 계급·종교·지방·원하는 나라·혁명 vs 전쟁 축으로 바꿔 보며 같은 진영 안의 엇갈림을 봅니다.
3. **내전 속의 내전**: 공화파와 국민파 내부 갈등을 세력별 세로줄 순서도로 그렸습니다. 줄이 끊긴 곳에서 그 세력은 사라지거나 흡수됐습니다.
4. **국제전의 리허설**: 외국인 병력 추정 범위, 나라별로 보낸 것·원한 것·얻은 것.
5. **인물 사전**, **예술가들이 본 스페인**(카드를 열면 지도에 발자취), **그 후**(결산·패인·아이러니).

사건 갈래는 전투(◆) · 정치·내분 · 국제 · 예술·문화 네 줄이며, 시간 띠 위에서 골라 볼 수 있습니다.

## 어떻게 그려지나

- **지도**: 스페인 국립지리원(IGN) 행정 경계(es-atlas 0.6.0, CC BY 4.0)와 Natural Earth(world-atlas 2.0.2)를
  메르카토르로 투영하고 단순화해 SVG 경로로 바꿨습니다(`tools/build-geo.mjs` → `js/geo.js`).
- **전선**: 시기마다 공화파 지역을 경위도 다각형으로 정의하고 국토 모양으로 잘라(clipPath) 칠합니다.
  다각형은 아라곤·과달라하라·마드리드·에스트레마두라·북부 같은 구간을 조합해 만들고,
  `tools/check-fronts.mjs`가 도시 302곳의 점령 상황으로 검증한 뒤 같은 다각형으로 영토 비율을 잽니다.
- **시점 이동**: 사건마다 중심과 배율이 있어 지도가 그곳으로 날아간 뒤 화살표와 표지가 그려집니다.
  글자와 표지는 확대해도 화면 크기가 그대로입니다.
- 사망자·병력 수는 연구마다 차이가 커서 범위로 적었습니다. 전선은 단순화한 근사선입니다.

## 파일 구조

```
index.html              화면 골격
css/style.css           디자인 토큰(라이트/다크)과 레이아웃
js/geo.js               (생성됨) 국토·주 경계·주변국 SVG 경로와 투영 상수
js/places.js            지명 사전(한글·현지 이름, 경위도)
js/fronts.js            시기별 전선 다각형과 영토 비율
js/data.js              세력, 갈등 축, 인물, 예술가, 내전 속의 내전, 외국 개입, 결산
js/events.js            타임라인 사건
js/map.js               지도 엔진: 전선, 화살표, 표지, 지도 밖 방향, 확대·이동
js/app.js               전보 패널, 시간 띠, 사상 지도, 순서도, 그래프, 서랍
tools/build-geo.mjs     TopoJSON → js/geo.js
tools/check-fronts.mjs  전선 검증과 영토 비율 측정
tools/bundle.mjs        한 파일짜리 배포본
```

```sh
npm pack es-atlas@0.6.0 world-atlas@2.0.2   # 데이터만 받는다(설치 스크립트 없음)
node tools/build-geo.mjs <es-atlas>/es/provinces.json <world-atlas>/countries-10m.json
node tools/check-fronts.mjs                  # 도시 302곳 검증 + 영토 비율
node tools/bundle.mjs                        # ../dist/spanish-civil-war.html
```

## 사건 추가하기

`js/events.js`의 `EVENTS`에 항목을 넣습니다. 순서는 날짜로 자동 정렬됩니다.

```js
{
  id: 'brunete', date: '1937-07-06', end: '1937-07-25', lane: 'war', phase: 'p3b',
  at: 'brunete', zoom: [[-3.95, 40.48], 4.2],          // 지명 키 또는 [경도, 위도], 배율
  title: '브루네테 전투',
  vs: [['pce', '국제여단'], ['army', '독일']],          // FACTIONS 키 또는 외국 이름
  arrows: [{ from: 'escorial', via: [[-4.03, 40.5]], to: 'brunete', kind: 'rep', label: '7.6 공세' }],
  areas: [{ kind: 'repgain', poly: [[-4.12, 40.48], …] }],
  why: '…', result: '…', meaning: '…',
  people: ['rojo'], artists: ['capa'], notes: { capa: '이 사건과 작가의 연결' },
}
```

전선 시기를 새로 만들려면 `js/fronts.js`의 `PHASES`에 구간을 조합해 넣고,
`tools/check-fronts.mjs`의 `EXPECT`에 그 시점에 반드시 맞아야 하는 도시를 적은 뒤 검증합니다.
