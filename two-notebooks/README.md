# 두 권의 수첩

조지 오웰과 니코스 카잔차키스의 눈으로, 1인칭으로 겪는 스페인 내전(1936–1937).

> 한 사람은 총을 들고 바르셀로나에 내렸다. 한 사람은 기자증을 들고 살라망카에 내렸다.
> 같은 전쟁의 양쪽 끝에서, 두 작가는 각자의 수첩에 무엇을 적었을까.

## 플레이

`index.html`을 브라우저로 열면 됩니다. 별도 빌드나 서버가 필요 없습니다.

장면마다 그림을 둘러보고, 행동을 고르고, 그날 밤 수첩에 한 줄을 적습니다.
적고 나면 그 사람이 실제로 쓴 문장이나 남긴 기록이 드러나고, 내 문장이 그들의 마음 어디쯤에 닿았는지 보여 줍니다.
정답을 맞히는 게임이 아닙니다. 같은 일을 몸으로 먼저 겪게 해서, 그들의 감정과 생각에 스스로 도달하도록 짰습니다.

키보드: `Space` 계속 · `1`–`4` 고르기 · `N` 수첩 열기 · `Esc` 닫기. 소리는 오른쪽 위에서 켭니다.

### 오웰의 수첩 (10장, 1936.12 – 1937.6, 그리고 그 뒤)

| 장 | 때와 곳 | 겪는 것 |
|---|---|---|
| 1 | 1936.12.26 바르셀로나 | 깃발·구두닦이·'동지'를 둘러보고, 엘리베이터 소년에게 팁을 건네 본다 |
| 2 | 레닌 병영 | 고를 수 없는 소속(ILP 소개장 → POUM), 이탈리아 민병대원의 악수 |
| 3 | 알쿠비에레 고지 | **다섯 밤**: 3시간씩 장작·음식·담배·초·적 감시에 나눠 쓴다 → "적은 꼴찌" |
| 4 | 우에스카 전선 | **겨누기**: 바지를 붙들고 뛰는 사람을 쏠 것인가 |
| 5 | 1937.4 바르셀로나 | 같은 람블라스에서 넉 달 사이 달라진 것 찾기, 첫 장의 문장 다시 읽기 |
| 6 | 5월 사태, 폴리오라마 지붕 | 같은 편끼리의 사흘, 그리고 **신문 네 장**을 내가 본 것과 맞춰 보기 |
| 7 | 5.20 토레 파비안 | 총상. 목소리가 나오지 않는 선택지, 죽는다고 생각한 순간의 첫 생각 |
| 8 | 6월 숨는 도시 | 아일린의 "나가요!", 압수된 수첩, 옷 고르기, 코프를 위해 전쟁부로 갈 것인가 |
| 9 | 6.23 국경 | 관광객처럼 보이기 |
| 10 | 잉글랜드 | "깊고 깊은 잠", 『1984』로 이어지는 것, 그리고 그 악수 |

장면마다 **'우리 편'(공화국 진영과 그 신문들)에 대한 믿음**과 **사람에 대한 믿음**이 움직이고,
마지막에 두 선의 궤적을 봅니다. 오웰은 앞의 것을 잃었고 뒤의 것은 커졌다고 썼습니다.

### 카잔차키스의 수첩 (11장, 1926년의 기억 – 1936.10–11 – 그 뒤)

| 장 | 때와 곳 | 겪는 것 |
|---|---|---|
| 1 | 1926 톨레도(기억) | 같은 크레타 사람 엘 그레코의 도시 |
| 2 | 1936.10.2 아테네 | 메탁사스 독재 아래의 신문, 한쪽 진영의 통행증 |
| 3 | 살라망카 | 그랜드 호텔과 '십자군', 같은 색 깃발의 두 스페인 |
| 4 | 우나무노의 서재 | **묻기**: "나는 파시스트도 볼셰비키도 아니다. 나는 혼자다." |
| 5 | 아빌라 | '문학' 특파원이라는 분류 |
| 6 | 톨레도 | **기억 ↔ 지금** 막대, 로르카의 소식, **기사 쓰기와 검열**(붉은 연필) |
| 7 | 헤타페 | **누가 싸우는가**: 보고 들은 것을 누르면 유럽 지도에 화살표가 그려진다 |
| 8 | 마드리드 앞 | 들어가지 못한 도시, 넘어가 볼 것인가 |
| 9 | 아테네 | 실린 기사 45편과 실리지 않은 것 |
| 10 | 1937.4 책 | 책으로 묶으며 고쳐 쓰기, 부제 「¡Viva la muerte!」 |
| 11 | 크레타 | "나는 아무것도 바라지 않는다…" |

**본 것**과 **신문에 실린 것**의 차이가 쌓이고, 마지막에 갈래별(영웅·폐허·양쪽의 폭력·양쪽을 도운 외국)로 봅니다.

### 두 권을 나란히

두 수첩을 다 읽으면 열립니다. 두 사람의 길(둘 다 마드리드에 들어가지 못했다), 엇갈린 시간,
두 사람의 그래프, 당신의 문장과 그들의 문장, 마지막 두 문장.

## 무엇이 사실인가

- 장소·날짜·사건은 기록을 따랐습니다. 1인칭 내레이션은 그들의 글과 연구를 바탕으로 다시 쓴 것입니다.
- '그들의 문장'은 종류를 표시합니다. **원문**(확인된 인용) · **요지**(글의 요약) · **기록**(확인된 사실) · **전해짐**(전해지는 이야기).
- 오웰의 인용은 『카탈루냐 찬가』(1938), 「스페인 전쟁을 돌아보며」(1942), 「나는 왜 쓰는가」(1946),
  시 「이탈리아 병사가 내 손을 잡았다」(1939), 시릴 코널리에게 보낸 편지(1937)에서 옮겼습니다(번역은 이 게임의 것).
- 카잔차키스는 원문 인용을 비문 하나로만 한정하고, 1936년 기사에 관한 연구(우나무노 인터뷰, 통행증, 톨레도와 헤타페, 45편의 기사, 1937년 책)를 요지로 옮겼습니다.
  프랑코가 그에게 한 말은 기록을 확인하지 못해 옮기지 않았습니다.
- 5월 사태의 신문 제목, 톨레도 안내 장교와 검열관의 말은 당시의 주장과 정황을 요약해 만든 것입니다. 게임 안에 그렇게 밝혀 두었습니다.

## 어떻게 그려지나

- **그림**: 장면 그림은 모두 캔버스에 코드로 그립니다(`js/plates.js`). 좌표는 가로 100 × 세로 75 단위라 화면 크기와 상관없이
  둘러보기 지점이 같은 물건 위에 놓입니다. 오웰의 장면은 평평하고 분명한 색으로, 카잔차키스의 장면은 엘 그레코처럼
  굽이치는 하늘과 길쭉한 몸으로 그렸습니다. 정지된 층은 한 번만 그려 두고 움직이는 층(깃발, 불, 눈, 연기, 달리는 사람)만 초당 30번 다시 그립니다.
- **소리**: 녹음 파일 없이 Web Audio로 바람·거리·참호·기차·바다·총성을 만듭니다(`js/sound.js`).
- **지도**: Natural Earth(world-atlas 2.0.2)를 단순화한 경로입니다(`tools/build-map.mjs` → `js/mapdata.js`).
- 진행은 장면이 시작될 때마다 이 브라우저(localStorage)에만 저장됩니다.

## 파일 구조

```
index.html          화면 골격
css/style.css       디자인 토큰(라이트/다크)과 레이아웃, 두 수첩의 종이와 잉크
js/mapdata.js       (생성됨) 이베리아·유럽 경로
js/maps.js          표지의 두 길, 장면 위치, 헤타페의 유럽 지도
js/echoes.js        그들의 문장: 인용·요지·기록과 출처
js/paint.js         그림 판(캔버스 렌더러)과 붓(사람, 깃발, 능선, 구름…)
js/plates.js        장면 그림 21장
js/sound.js         Web Audio 배경 소리와 효과음
js/orwell.js        오웰의 수첩 10장
js/kazantzakis.js   카잔차키스의 수첩 11장
js/games.js         다섯 밤, 겨누기, 신문, 기억, 누가 싸우는가, 기사와 검열, 책
js/engine.js        장면 엔진(비트 실행, 수첩, 저장)
js/app.js           표지, 진행 화면, 수첩 서랍, 한 권의 끝, 두 권을 나란히
tools/build-map.mjs TopoJSON → js/mapdata.js
tools/bundle.mjs    한 파일짜리 배포본
```

```sh
npm pack world-atlas@2.0.2                 # 데이터만 받는다(설치 스크립트 없음)
node tools/build-map.mjs <world-atlas 폴더>  # js/mapdata.js
node tools/bundle.mjs                      # ../dist/two-notebooks.html
```

## 장면 추가하기

`js/orwell.js`나 `js/kazantzakis.js`의 `scenes`에 넣습니다. 비트는 위에서 아래로 실행됩니다.

```js
{
  id: 'o11', title: '…', when: '1937년 …', date: '1937-..-..', where: '…', at: [경도, 위도],
  paint: 'barcelona', params: { variant: 'apr' }, sound: 'city',
  beats: [
    { hist: '역사 메모' },
    { say: '내레이션', who: '말하는 사람(선택)' },
    { look: { prompt: '…', need: 3, spots: [{ id, x, y, label, text, note }] } },  // x 0–100, y 0–75
    { choose: { prompt: '…', options: [{ label, then: [...], flag, set: { side: -1 } }], after: [...] } },
    { write: { prompt: '…', echo: 'o-five', options: [{ text, res: 2, reply: '…' }] } },  // res: 2 닿음 · 1 가까움 · 0 다름
    { echo: 'o-papers' }, { note: '…' }, { set: { people: 1 } }, { game: 'trench' },
    { if: s => s.flags.shot, then: [...], else: [...] },
  ],
}
```

새 문장은 `js/echoes.js`의 `ECHOES`에, 새 그림은 `js/plates.js`에 `{ base(g, p), anim(g, t, p), dyn: [...] }` 꼴로 넣습니다.
