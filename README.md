# 디렉터스 콘티

단편영화 「막차」의 감독이 되어 장면마다 연출을 결정하는 브라우저 게임입니다.
선택할 때마다 **콘티 패널과 평면도(블로킹 다이어그램)** 가 다시 그려지고,
OK · KEEP · 아쉬움 · NG 판정과 함께 그 이유를 알려 줍니다.

> 사진가 서연은 10년 만에 아버지를 만난다. 그는 오늘 밤 막차로 도시를 떠난다고 한다.

## 플레이

`index.html`을 브라우저로 열면 됩니다. 별도 빌드나 서버가 필요 없습니다.

1. 프리 프로덕션에서 화면비(1.33 / 1.85 / 2.39)를 고릅니다. 이후 모든 콘티가 이 비율로 그려집니다.
2. 6개 씬, 16번의 결정. 시나리오와 연출 의도를 읽고, 선택지 카드의 콘티를 비교해 한 컷을 고릅니다.
3. 마지막에 완성된 **콘티북**, 연출 스타일 분석, 다시 생각해 볼 컷, 전체 **애니매틱**이 나옵니다.

키보드: `1`–`4` 선택 · `Enter` 결정 · `→` 다음 · `Esc` 닫기

## 배우는 것

| 씬 | 공간 | 연출 포인트 |
|---|---|---|
| 프리 | — | 화면비 |
| S#1 | 비 오는 도심 횡단보도 | 샷 사이즈(설정 숏), 카메라 무빙(크레인), 역광과 비 |
| S#2 | 24시 식당 | 마스터 숏, **180도 법칙**, 감정에 따른 샷 사이즈 진행 |
| S#3 | 식당 (계속) | 카메라 앵글과 권력, **30도 법칙·점프 컷**, 여백 |
| S#4 | 암실 | 동기 있는 조명, 인서트와 시점, 달리 인·줌·돌리 줌의 차이 |
| S#5 | 역으로 가는 길 | 핸드헬드·스테디캠, **화면 방향**, 편집 리듬 |
| S#6 | 플랫폼 | 프레임 속 프레임, 엔딩 이미지(수미상관 보너스) |

상단의 **연출 노트**에는 콘티 기호 읽는 법, 샷 사이즈·앵글·렌즈 비교 콘티, 무빙·연결 규칙·조명 용어가 정리되어 있습니다.

## 어떻게 그려지나

콘티는 미리 그린 그림이 아니라, 매번 작은 3D 장면을 핀홀 카메라로 투영해 SVG로 그립니다.

- 세트는 박스와 면으로 만든 3D 공간이고, 인물은 카메라를 향한 평면에 그린 뒤 원근 투영합니다.
- 인물이 **바라보는 방향과 카메라의 상대 각도**로 얼굴·팔·머리카락 배치가 결정됩니다.
  그래서 카메라가 180도 선을 넘으면 인물의 시선 방향이 실제로 뒤집혀 보입니다.
- 렌즈(mm)가 바뀌면 같은 클로즈업이라도 카메라 거리와 배경 압축, 피사계 심도(빛망울)가 달라집니다.
- 지평선(HL)은 카메라 높이에서 계산되므로 로우·하이 앵글의 차이가 가이드 선으로 보입니다.
- 빨간 화살표·점선 프레임(카메라 무빙), 파란 화살표(인물 동선)는 콘티 관례를 따릅니다.
- 애니매틱은 같은 장면을 시간에 따라 다시 투영해 무빙(크레인, 푸시 인, 돌리 줌, 핸드헬드)을 재생합니다.

## 파일 구조

```
index.html          화면 골격
css/style.css       디자인 토큰(라이트/다크)과 레이아웃
js/engine.js        벡터 수학, 카메라, 투영·클리핑, 씬 그래프
js/art.js           인물(서연·준호)과 소품 드로잉, 표정
js/render.js        조명 룩, 피사계 심도, 비, 콘티 기호, 평면도
js/sets.js          다섯 개의 세트: 도심 / 식당 / 암실 / 거리 / 플랫폼
js/story.js         시나리오, 결정, 선택지별 판정과 해설
js/game.js          진행 상태, 화면, 애니매틱 플레이어, 연출 노트
tools/bundle.mjs    모든 파일을 한 장의 HTML로 묶기
```

한 파일짜리 배포본이 필요하면:

```sh
node tools/bundle.mjs        # dist/directors-konti.html
```

## 결정 추가하기

`js/story.js`의 각 씬 `decisions` 배열에 항목을 추가합니다.

```js
{
  id: 's2d4', cut: 'C4', title: '…', lesson: '…', q: '질문', hint: '힌트',
  compare: true,                       // 앞 컷과 나란히 보여주기 (연결 규칙 학습용)
  base: { set: 'diner', look: 'diner', cast: [...], dur: 3 },
  sheet: { action: '…', dial: '…', sfx: '…' },
  options: [
    { id: 'A', label: '…', spec: 'CU · 85mm', desc: '…', grade: 'ok', style: { classic: 1 },
      shot: { cam: { frame: { who: 'seoyeon', size: 'CU', rel: 30 }, lens: 85 } },
      why: '판정 이유' },
  ],
  tip: '현장 팁',
}
```

카메라는 `{ pos, target, lens }`로 직접 지정하거나, `frame: { who, size, rel }`로 인물 기준
샷 사이즈를 지정하면 렌즈에 맞는 거리가 자동으로 계산됩니다. 진행 상황은 이 브라우저에만 저장됩니다.
