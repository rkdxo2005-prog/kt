# 또박또박 낭독기

글을 붙여넣으면 브라우저 음성(Web Speech API)으로 자연스럽게 읽어 주는 HTML 한 장짜리 도구입니다.
설치나 서버 없이 `tts-reader/index.html`을 브라우저로 열면 바로 씁니다.

## 무엇을 알아서 해 주나

- **한국어 + 영어 섞인 글**: 한국어는 한국어 목소리, `apple`, `Practice makes perfect.` 같은 영어 부분은 영어 목소리로 바꿔 가며 읽습니다.
- **약어는 한국식으로**: `AI` → 에이아이, `GPT-4` → 지피티 포, `PDF로` → 피디에프로, `MBTI` → 엠비티아이.
  `NASA`, `UNESCO`처럼 단어로 읽는 약어는 나사, 유네스코로 읽습니다. (설정에서 끌 수 있음)
- **학습 모드**: 세 단어 이하의 짧은 영어는 한 번 더, 천천히 들려줍니다.
- **기호 정리**: 마크다운(`#`, `-`, `**`), 링크 주소, 이모지, 괄호는 소리 내지 않고 쉼으로 바꿉니다. `3~5시` → 3에서 5시.
- **읽는 곳 표시**: 읽기 화면에서 지금 읽는 부분에 형광펜이 따라가고, 문장을 누르면 거기서부터 읽습니다.
- 전체 속도, 영어 부분 속도, 문장 사이 쉼, 목소리 높이, 한국어·영어 목소리를 각각 고를 수 있습니다.

## 더 사람 같은 목소리로 듣는 법

목소리 품질은 기기에 설치된 음성에 달려 있습니다.

- **Windows / Microsoft Edge**: “Microsoft SunHi Online (Natural)” 같은 Natural 음성이 가장 자연스럽습니다.
- **Mac / iPhone**: 설정 › 손쉬운 사용 › 음성 콘텐츠에서 한국어 “유나(향상됨)” 등을 내려받으세요.
- **Chrome**: “Google 한국의” 음성을 쓸 수 있습니다.

목록에서 ★가 붙은 목소리가 고품질 음성입니다.

## 단축키

`Space` 재생/일시정지 · `←` `→` 문장 이동 · `Esc` 정지 · 편집 중 `Ctrl/Cmd + Enter` 바로 읽기
